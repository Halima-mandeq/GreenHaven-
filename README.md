# 🌿 GreenHaven - Eco-Luxury Real Estate & In-Villa Dining Platform

**GreenHaven** is a modern, high-performance, eco-luxury real estate application designed for premium green villas, sustainable residences, and exclusive lifestyle amenities. Built with React, TypeScript, Vite, and Tailwind CSS, it offers an immersive UI with floor plans, 360° virtual walkthroughs, custom feature filters, and an integrated farm-to-table in-villa dining order system.

---

## ✨ Key Features

- **🌐 Dual-Language Support (Somali & English)**: Instant, full-page language switching with localized copy and terms.
- **🔍 Advanced Property Search & Checkbox Filters**:
  - Filter by price slider and property categories (*Villa*, *Resort*, *Eco-Haven*, *Glass House*).
  - Multi-select feature checkboxes for **Private Pool**, **Solar Energy Grid**, **Gym Access**, **Smart Home Automation**, **Garden & Forest Access**, and **24/7 Security**.
- **🏡 Interactive Property Showcase**:
  - High-definition image galleries with full-screen zoom.
  - **2D Floor Plan Blueprint View**: Interactive room dimensions and layout structure.
  - **360° Virtual Walkthrough Tour**: Immersive hotspot navigation inside properties.
  - **Mortgage Calculator**: Live monthly payment estimations based on down payments and interest rates.
- **🍽️ GreenHaven Organic Bistro & In-Villa Dining**:
  - Farm-to-table organic food menu with category filters (Breakfast, Mains, Smoothies, Desserts).
  - Interactive ordering cart with villa/suite selection and custom culinary notes for the Executive Chef.
- **💳 VIP Gold Pass Membership**:
  - Interactive 3D foil shimmer card preview showcasing exclusive member perks like private helicopter access and private golf course privileges.
- **🌿 Sustainable Building Materials & Eco-Features**:
  - Interactive breakdown of eco-glass, teak wood, and solar energy efficiency.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS (v4)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Architecture**: Responsive Single Page Application (SPA)

## 🚀 Getting Started

Follow these instructions to run the project locally on your machine:

### Prerequisites
Make sure you have **Node.js** (v18 or higher) and **npm** installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/greenhaven-eco-realestate.git
   cd greenhaven-eco-realestate
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
